# 템플릿 사용 가이드

> 템플릿은 노트를 만들 때 미리 정해진 양식을 자동으로 불러오는 기능입니다.
> 매번 처음부터 작성하지 않아도 됩니다!

---

## KNOT-vault 기본 제공 템플릿 3가지

| 템플릿 | 언제 사용 |
|--------|----------|
| 📝 일반 노트 | 아이디어, 메모, 공부 내용 정리할 때 |
| 🗣️ 회의·대화 기록 | 회의 내용, AI와 나눈 대화를 정리할 때 |
| 🗂️ 프로젝트 기획서 | 새 프로젝트를 시작할 때 |

---

## 템플릿 사용 방법

### 방법 1. 새 노트 만들 때 바로 적용 (가장 쉬움)

1. 왼쪽 사이드바에서 노트를 저장할 폴더 **우클릭**
2. **"새 노트 생성"** 클릭
3. 노트가 열리면 **Ctrl + P** 누르기 (명령어 팔레트 열기)
4. **"Templater: 템플릿 삽입"** 또는 **"Insert Template"** 검색
5. 원하는 템플릿 선택 → 자동으로 양식이 채워짐

### 방법 2. 기존 노트에 템플릿 추가하기

1. 템플릿을 적용할 노트 열기
2. **Ctrl + P** 누르기
3. **"Templater: Insert Template"** 검색 후 선택
4. 원하는 템플릿 선택

---

## 각 템플릿 설명

### 📝 일반 노트
```
핵심 요약 → 내용 → 관련 노트 → 출처
```
- 가장 기본적인 노트 양식
- 공부한 내용, 아이디어, 메모 등 무엇이든 사용 가능

### 🗣️ 회의·대화 기록
```
기본 정보 → 안건 → 논의 내용 → 결정 사항 → 액션 아이템
```
- 회의 날짜, 참석자, 장소 자동 기록
- 할 일(액션 아이템) 담당자와 기한 관리

### 🗂️ 프로젝트 기획서
```
요약 → 배경/목적 → 목표 → 일정 → 체크리스트 → 진행 기록
```
- 프로젝트 처음 시작할 때 사용
- 체크리스트로 진행 상황 관리

## AI와 함께 템플릿 활용하기

템플릿을 열고 Gemini·Claude·Codex 채팅창에서 이렇게 말해보세요:

> "지금 열린 노트를 기획서 형식으로 채워줘"
> "오늘 회의 내용을 회의록 양식에 맞게 정리해줘"
> "이 아이디어를 노트로 정리해줘"

AI가 템플릿 양식에 맞게 내용을 자동으로 채워줍니다!

## 나만의 템플릿 만들기

`Settings/Templates/` 폴더에 새 파일을 만들면 됩니다.

**날짜 자동 입력 문법 (Templater):**
- `<% tp.date.now("YYYY-MM-DD") %>` → 오늘 날짜 자동 입력
- `<% tp.file.title %>` → 파일 이름 자동 입력
