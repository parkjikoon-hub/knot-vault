# Claude → 옵시디언 자동저장 워크플로우

> **박지군과 Claude가 함께 만든 자료가 옵시디언에 자동으로 저장되는 전 과정을 담은 실전 가이드입니다.**
> "어떻게 말하면 어떤 파일이 어디에 저장되는가"를 중심으로 설명합니다.

---

## 1. 자동저장이 작동하는 원리

```
박지군이 Claude에게 말한다
        ↓
Claude가 내용을 파악하고 frontmatter를 자동 생성한다
        ↓
MCP(mcp-obsidian)를 통해 REST API 호출
        ↓
옵시디언 CMDS-vault에 .md 파일로 저장된다
        ↓
옵시디언에서 즉시 확인 가능
```

**핵심**: 복사·붙여넣기 없이, 대화만으로 노트가 만들어집니다.

---

## 2. 콘텐츠 유형별 저장 워크플로우

---

### 📋 워크플로우 A — 기획서·아이디어

**언제 사용**: 새 프로젝트, 서비스, 연구과제, 앱 아이디어가 생겼을 때

#### 대화 방법

```
"[아이디어/프로젝트명] 기획서를 작성해서 옵시디언에 저장해줘"

또는 구체적으로:
"AI 기반 학습 플랫폼 서비스 기획서를 작성해서
 900번 Divisions에 CMDS 형식으로 저장해줘"
```

#### 자동 생성되는 파일 예시

```
파일명: AI-기반-학습-플랫폼-기획서.md
저장위치: CMDS-vault/
카테고리: 900 Divisions
```

```yaml
---
type: project
aliases:
  - AI 학습 플랫폼
  - 교육 플랫폼 기획
description: Project plan for AI-based learning platform. Covers target users, core features, development phases, and business model.
author:
  - "[[박지군]]"
date created: 2026-05-02
date modified: 2026-05-02
tags:
  - 기획서
  - AI
  - 교육
  - 프로젝트
status: in-progress
---
```

---

### 📚 워크플로우 B — 연구과제·논문 정리

**언제 사용**: 논문 요약, 연구 계획서, 문헌 정리가 필요할 때

#### 대화 방법

```
"이 논문을 요약해서 200번 Literature에 저장해줘"

"[연구주제]로 연구 계획서를 작성해서 저장해줘"

"다음 3편의 논문을 하나의 Literature Review 노트로
 합쳐서 저장해줘: [논문1], [논문2], [논문3]"
```

#### 자동 생성되는 파일 예시

```
파일명: 생성AI-교육-적용-문헌리뷰.md
저장위치: CMDS-vault/
카테고리: 200 Literature
```

---

### 💡 워크플로우 C — 아이디어 빠른 수집

**언제 사용**: 지나가다 떠오른 아이디어, 읽은 기사, 유튜브 내용

#### 대화 방법

```
"방금 [아이디어]가 떠올랐어. 100번 Themes에 빠르게 저장해줘"

"이 기사 내용을 요약해서 Theme 노트로 만들어줘: [URL 또는 내용]"

"[유튜브 내용] 이거 나중에 활용할 것 같아서 저장해줘"
```

#### 팁: 빠른 수집은 완성도보다 속도가 중요
- 완벽한 노트 X → 일단 저장하고 나중에 /merge로 발전시킴
- Claude가 핵심만 추출해서 간결하게 저장

---

### 🔬 워크플로우 D — 프로그램·도구 개발

**언제 사용**: 앱, 웹서비스, 자동화 도구, 프롬프트 개발

#### 대화 방법

```
"[프로그램명] 개발 계획서를 작성해서 저장해줘"

"이 프롬프트 템플릿을 400번 Methodologies에 저장해줘"

"지금까지 만든 [도구명] 사용법을 500번 Products에 정리해서 저장해줘"
```

---

### 📝 워크플로우 E — 대화 내용 전체 저장

**언제 사용**: 세션이 끝날 때, 긴 논의를 기록하고 싶을 때

#### 대화 방법

```
"지금까지 대화한 내용을 요약해서 옵시디언에 저장해줘"

"이번 세션에서 기획한 [주제] 내용을 정리해서
 노트로 만들어줘"

"오늘 논의한 내용의 핵심만 뽑아서 액션 아이템과 함께 저장해줘"
```

#### 자동 생성되는 파일 예시

```
파일명: 2026-05-02-세션-AI플랫폼-기획.md
저장위치: CMDS-vault/
내용: 핵심 논의 + 결정사항 + 다음 액션
```

---

### 🔄 워크플로우 F — 기존 노트 발전시키기

**언제 사용**: 이전에 저장한 아이디어를 심화할 때

#### 대화 방법

```
"볼트에서 [주제] 관련 노트 찾아서 보여줘"
        ↓
"이 노트를 발전시켜서 업데이트해줘"

또는:
"[노트명.md]를 읽고 내용을 보완해서 다시 저장해줘"

"100번에 저장된 AI 교육 아이디어들을 모아서
 하나의 기획서로 합쳐줘"
```

## 3. 카테고리 자동 분류 기준

Claude가 내용을 보고 자동으로 판단하는 기준입니다.

| 내용의 성격 | Claude가 선택하는 카테고리 |
|------------|--------------------------|
| 새 아이디어, 관심 주제, 기사 스크랩 | **100 Themes** |
| 논문, 책, 외부 지식 정리 | **200 Literature** |
| 설문, 인터뷰, 데이터 수집 결과 | **300 Data** |
| 분석 방법, 코드, 프롬프트 | **400 Methodologies** |
| 앱·도구·플랫폼 사용법 | **500 Products** |
| 전문 분야 심화 지식 | **600 Specialties** |
| 블로그, SNS, 유튜브 스크립트 | **700 Creatives** |
| 강의자료, 보고서, 최종 산출물 | **800 Outputs** |
| 프로젝트·팀 운영 문서 | **900 Divisions** |

### 분류가 애매할 때

```
"이 내용을 어느 카테고리에 넣어야 할지 모르겠어"
→ Claude에게 말하면 이유와 함께 추천해줌
```

## 4. 저장 시 파일명 규칙

Claude가 자동으로 파일명을 만들 때 따르는 규칙:

```
[주제-키워드]-[내용유형].md

예시:
- AI-교육-플랫폼-기획서.md
- 생성AI-문헌리뷰-2026.md
- 옵시디언-Claude-연동-설정.md
- 온라인강의-커리큘럼-초안.md
```

날짜가 중요한 경우:
```
2026-05-02-[주제]-[내용유형].md

예시:
- 2026-05-02-세션-기획논의.md
- 2026-05-02-아이디어-빠른메모.md
```

## 5. 실전 시나리오 — 처음부터 끝까지

### 시나리오 1: 클로드와 기획한 서비스를 노트로 저장

```
1단계: 아이디어 탐색
박지군: "AI를 활용한 개인 맞춤형 독서 추천 앱 어떻게 생각해?"
Claude: [아이디어 분석 + 발전]

2단계: 기획서 요청
박지군: "지금까지 논의한 내용으로 기획서 초안을 만들어서
         900번 Divisions에 저장해줘"
Claude: [기획서 작성 + 옵시디언에 자동 저장]

3단계: 확인
박지군: [옵시디언 열어서 새 파일 확인]

4단계: 심화
박지군: "방금 저장한 기획서에 경쟁사 분석 섹션을 추가해줘"
Claude: [기존 파일 읽기 + 수정 + 다시 저장]
```

### 시나리오 2: 연구 자료 수집 및 정리

```
1단계: 자료 수집
박지군: "AI와 교육에 관한 최신 트렌드를 정리해서
         100번 Themes에 빠르게 저장해줘"
Claude: [검색 + 요약 + 저장]

2단계: 심화 정리
박지군: "방금 저장한 내용을 바탕으로
         Literature Review 노트를 200번에 만들어줘"
Claude: [기존 노트 읽기 + 심화 작성 + 저장]

3단계: 산출물 제작
박지군: "이 Literature 노트를 바탕으로
         학회 발표용 개요를 800번 Outputs에 저장해줘"
Claude: [노트 읽기 + 발표 개요 작성 + 저장]
```

### 시나리오 3: 세션 종료 시 자동 기록

```
세션 마무리 시:
박지군: "오늘 논의한 내용 전체를 정리해서 저장해줘.
         핵심 결정사항과 다음에 할 일도 포함해서."

Claude: [대화 전체 요약]
        [결정사항 리스트]
        [다음 액션 아이템]
        [옵시디언에 세션 노트로 저장]
```

## 6. 볼트에서 찾고 수정하는 방법

### 볼트 파일 목록 확인

```
"볼트에 어떤 파일들이 있어?"
→ Claude가 전체 파일 목록 나열
```

### 특정 내용 검색

```
"볼트에서 [키워드] 관련 내용 찾아줘"
"[파일명.md] 파일 내용 보여줘"
```

### 기존 파일 수정

```
"[파일명.md]에 [내용] 추가해줘"
"[파일명.md]의 [섹션명] 부분을 수정해줘"
"[파일명.md]를 최신 내용으로 업데이트해줘"
```

---

## 7. 주의사항

### 옵시디언은 항상 실행 중이어야 함
MCP가 옵시디언 앱 안의 서버를 통해 통신하므로
옵시디언이 꺼져 있으면 파일 저장이 안 됩니다.

### 파일 저장 후 확인 방법
옵시디언에서 `Ctrl + Shift + F` (전체 검색)으로
방금 저장한 파일명을 검색하면 바로 확인 가능합니다.

### 중요한 내용은 저장 요청을 명시적으로
Claude는 자동으로 저장하지 않습니다.
"저장해줘", "노트로 만들어줘" 처럼 명시적으로 요청해야 합니다.

## 8. 빠른 참조 — 상황별 한 줄 요청

| 상황 | Claude에게 이렇게 말하기 |
|------|------------------------|
| 새 아이디어가 떠올랐다 | "이 아이디어를 100번 Themes에 저장해줘: [내용]" |
| 논문을 읽었다 | "이 논문 요약을 200번 Literature에 저장해줘: [내용]" |
| 기획을 마쳤다 | "지금 기획한 내용을 기획서로 만들어서 900번에 저장해줘" |
| 대화를 기록하고 싶다 | "이번 대화 내용을 정리해서 저장해줘" |
| 어디에 넣을지 모른다 | "이 내용 적합한 카테고리에 저장해줘" |
| 기존 노트를 발전시키고 싶다 | "[파일명] 읽고 [추가할 내용] 더해서 업데이트해줘" |
