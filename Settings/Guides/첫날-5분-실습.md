# 첫날 5분 실습 — AI와 함께 첫 노트 만들기

> 설치를 마쳤나요? 축하합니다!
> 이제 5분 안에 AI와 함께 첫 번째 노트를 만들어볼게요.
> 어렵지 않습니다. 그냥 따라하기만 하면 됩니다.

---

## 준비 확인

아래 두 가지가 되어 있으면 시작할 수 있습니다.

- [ ] 옵시디언에서 KNOT-vault가 열려 있다
- [ ] Gemini Obsidian 플러그인이 켜져 있다 (✨ 아이콘이 사이드바에 보임)

안 되어 있으면 → [[START HERE]] 로 돌아가서 설치를 먼저 완료해주세요.

---

## 실습 1. 첫 번째 AI 대화 (1분)

**1.** 왼쪽 사이드바에서 **✨ 아이콘** 클릭
→ 오른쪽에 Gemini 채팅창이 열립니다

**2.** 아래 문장을 채팅창에 그대로 붙여넣고 **Shift+Enter**

```
안녕! 나는 오늘 처음으로 KNOT-vault를 설치했어. 
옵시디언과 AI를 활용해서 노트를 잘 정리하고 싶은데, 
초보자인 나에게 오늘 당장 해볼 수 있는 것 3가지를 알려줘.
```

**3.** Gemini가 답변해줍니다 🎉

> 어떤가요? 이게 전부입니다. 이제 AI와 대화하면서 노트를 만들 수 있어요.

---

## 실습 2. 대화 내용을 노트로 저장 (1분)

방금 나눈 대화를 노트로 저장해볼게요.

**1.** 채팅창에 아래 문장 입력 후 **Shift+Enter**

```
방금 알려준 내용을 노트로 저장해줘.
```

**2.** 잠시 후 `AI/Gemini/` 폴더에 노트가 자동 생성됩니다
**3.** 왼쪽 폴더 목록에서 `AI → Gemini` 폴더를 클릭해서 확인해보세요

---

## 실습 3. 템플릿으로 나만의 노트 만들기 (2분)

이번엔 빈 노트에 양식을 불러와볼게요.

**1.** 키보드에서 **Ctrl + N** 누르기 → 새 노트 생성
**2.** 노트 제목에 `나의 첫 번째 노트` 입력 후 Enter
**3.** **Ctrl + P** 누르기 → 검색창이 열림
**4.** `Insert Template` 입력 → **"Templater: Insert Template"** 클릭
**5.** **📝 일반 노트** 선택
**6.** 양식이 자동으로 채워집니다!

**7.** 이제 채팅창에 아래 문장 입력

```
내가 오늘 KNOT-vault를 처음 설치했어. 
이걸 앞으로 어떻게 활용하면 좋을지 
지금 열린 노트에 들어갈 내용으로 정리해줘.
```

**8.** AI가 노트 내용을 채워줍니다. 복사해서 노트에 붙여넣기!

---

## 실습 4. 현재 노트를 AI에게 분석시키기 (1분)

노트를 열어두면 AI가 내용을 자동으로 참고합니다.

**1.** 방금 만든 노트가 열린 상태에서
**2.** 채팅창에 아래 입력

```
지금 열린 노트를 보고, 내용을 더 풍부하게 만들 수 있는 아이디어 3가지 알려줘.
```

**3.** AI가 노트 내용을 읽고 제안해줍니다
