# Codex Obsidian 사용 가이드

> OpenAI Codex CLI를 옵시디언 안에서 바로 사용하는 플러그인
> 코드 작성, 분석, 자동화에 특화된 AI입니다.

---

## 시작 전 확인

- [ ] 옵시디언이 설치되어 있다
- [ ] KNOT-vault를 옵시디언에서 열었다
- [ ] Node.js가 설치되어 있다 (아래 방법 참고)
- [ ] OpenAI 계정이 있다

---

## STEP 1. Node.js 설치 확인

1. 윈도우 검색창에서 **"PowerShell"** 검색 → 실행
2. 아래 입력 후 Enter:
   ```
   node --version
   ```
3. `v20.x.x` 처럼 나오면 설치됨 → STEP 2로 이동

**없다면:**
1. **https://nodejs.org** 접속
2. **"LTS"** 버튼 클릭 → 다운로드 → 설치

---

## STEP 2. Codex CLI 설치

PowerShell을 열어서 아래 명령어 입력 후 Enter:

```
npm install -g @openai/codex@latest
```

설치 완료 확인:
```
codex --version
```
버전 숫자가 나오면 설치 성공입니다.

---

## STEP 3. OpenAI 로그인

PowerShell에서:
```
codex auth
```
입력 후 Enter → 브라우저가 열리면 OpenAI 계정으로 로그인

---

## STEP 4. 플러그인 활성화

1. 옵시디언 설정(⚙️) → **"커뮤니티 플러그인"**
2. **"제한 모드 해제"** 클릭
3. **"Codex Obsidian"** 토글 **ON**

---

## STEP 5. 사용 시작!

왼쪽 사이드바에서 **💻 터미널 아이콘** 클릭
→ 오른쪽에 Codex 채팅창이 열립니다

---

## 승인 모드 설명

설정에서 Codex가 명령을 실행할 때 어떻게 동작할지 선택할 수 있습니다.

| 모드 | 설명 | 추천 대상 |
|------|------|----------|
| **제안 모드** | 실행 전에 항상 확인 요청 | 초보자 추천 |
| 자동 모드 | 안전한 명령은 자동 실행 | 중급자 |
| 전체 자동 | 모든 명령 자동 실행 | 고급자 |

> 처음에는 반드시 **"제안 모드"** 로 시작하세요.

## 자주 묻는 질문

**Q. Codex는 유료인가요?**
A. OpenAI 계정이 필요하며, API 사용량에 따라 요금이 발생합니다.

**Q. "codex를 찾을 수 없습니다" 오류가 나요**
A. PowerShell에서 `codex --version`을 입력해보세요. 설치가 안 된 경우 STEP 2를 다시 진행하세요.

**Q. Codex와 ChatGPT의 차이는 뭔가요?**
A. Codex는 코드 작성과 실행에 특화된 AI입니다. 일반 대화보다 코딩, 자동화 작업에 더 적합합니다.
