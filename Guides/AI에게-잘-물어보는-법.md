# AI에게 잘 물어보는 법

> AI는 질문을 구체적으로 할수록 더 좋은 답변을 줍니다.
> 복사해서 바로 쓸 수 있는 질문 예시를 모아놨습니다.

---

## 기본 원칙

**나쁜 질문** → "정리해줘"
**좋은 질문** → "이 내용을 초보자도 이해할 수 있게, 3가지 핵심으로 정리해줘"

차이점: **누가, 무엇을, 어떤 형식으로** 가 들어가면 훨씬 좋아집니다.

---

## 상황별 질문 예시 모음

### 📝 노트 정리할 때

```
이 노트의 핵심을 3줄로 요약해줘.
```
```
이 내용에서 가장 중요한 개념 5가지를 뽑아줘.
```
```
이 노트를 읽지 않은 사람에게 설명한다면 어떻게 말할까?
```
```
이 내용의 빠진 부분이나 보완할 점이 있으면 알려줘.
```

---

### 🗂️ 기획서·문서 만들 때

```
아래 아이디어를 기획서 형식으로 만들어줘.
제목, 배경, 목표, 실행 방법, 기대 효과 순서로 작성해줘:

[아이디어 내용]
```
```
이 기획서의 약점이 뭔지 솔직하게 말해줘.
투자자 입장에서 반박할 수 있는 질문도 알려줘.
```
```
이 내용을 1페이지 요약본으로 만들어줘.
핵심만 남기고 나머지는 과감하게 빼줘.
```

---

### 📚 공부·학습할 때

```
[개념]을 초등학생도 이해할 수 있게 설명해줘.
그리고 실생활 예시도 하나 들어줘.
```
```
[주제]에 대해 공부하려고 해.
어디서부터 시작하면 좋을지 순서를 알려줘.
```
```
이 개념과 비슷한 것, 다른 것을 비교해서 표로 만들어줘.
```

---

### 💼 업무·프로젝트 관리할 때

```
이 프로젝트에서 리스크가 될 수 있는 것들을 알려줘.
그리고 각각 어떻게 대비하면 좋을지도 말해줘.
```
```
오늘 해야 할 일이 너무 많아. 우선순위를 정해줘:

[할 일 목록]
```
```
이 회의 내용을 보고, 다음 회의 전까지 
각자 해야 할 일을 정리해줘.
```

---

### 💡 아이디어 발전시킬 때

```
이 아이디어의 장점 5가지, 단점 5가지를 알려줘.
```
```
비슷한 서비스나 제품이 있으면 알려줘.
우리 아이디어와 어떻게 다른지 비교해줘.
```
```
이 아이디어를 더 구체적으로 만들려면 
어떤 질문에 답해야 할까?
```

---

### 🔍 모를 때 그냥 물어보기

AI는 어떤 질문이든 답해줍니다. 너무 고민하지 마세요.

```
옵시디언에서 [하고 싶은 것]을 하려면 어떻게 해?
```
```
[이 기능]이 뭔지 모르겠어. 쉽게 설명해줘.
```
```
내가 지금 하려는 게 맞는 방법인지 확인해줘.
내가 하려는 것: [내용]
```
