# Claude Obsidian 사용 가이드

> Obsidian 안에서 Claude AI와 대화하고 노트를 자동 생성하는 플러그인
> (기존 Obsidian Code / cc-obsidian 을 KNOT 브랜드로 변경한 버전)

---

## 사전 준비

Claude Code CLI가 설치되어 있어야 합니다.

### Claude Code 설치 확인
터미널에서:
```
claude --version
```

없으면 설치:
```
npm install -g @anthropic-ai/claude-code
```

---

## 플러그인 활성화

설정 → 커뮤니티 플러그인 → **Claude Obsidian** 토글 ON

---

## 사용 방법

왼쪽 사이드바에서 Claude 아이콘 클릭 → 채팅창 열림

Claude Code가 실행 중이면 자동으로 연동됩니다.
