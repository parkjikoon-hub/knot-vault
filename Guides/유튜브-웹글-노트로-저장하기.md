# 유튜브·웹 글을 노트로 저장하기

> 유튜브 영상이나 웹 기사를 AI에게 주면
> 핵심 내용을 자동으로 노트로 정리해줍니다.

---

## 유튜브 영상 요약하기

**1.** 유튜브에서 요약하고 싶은 영상 열기
**2.** 주소창의 URL 복사 (예: `https://www.youtube.com/watch?v=xxxxx`)
**3.** Gemini 채팅창(✨)에 아래처럼 입력

```
이 유튜브 영상을 요약해줘:
https://www.youtube.com/watch?v=xxxxx

핵심 내용, 주요 포인트, 기억할 것들을 노트 형식으로 정리해줘.
```

**4.** 요약이 완성되면 → "노트로 저장해줘" 입력
**5.** `AI/Gemini/` 폴더에 자동 저장!

---

## 웹 기사·블로그 요약하기

**1.** 저장하고 싶은 웹페이지 URL 복사
**2.** 채팅창에 아래처럼 입력

```
이 글을 읽고 핵심 내용을 정리해줘:
https://www.example.com/article

- 주요 주장 3가지
- 기억할 핵심 문장
- 내 생각에 활용할 수 있는 아이디어
```

---

## 긴 글을 직접 붙여넣기

URL이 안 열리는 경우, 내용을 직접 복사해서 붙여넣어도 됩니다.

```
아래 글을 요약해줘:

[여기에 글 내용 붙여넣기]

핵심만 3줄로 정리하고, 중요한 개념은 따로 설명해줘.
```
