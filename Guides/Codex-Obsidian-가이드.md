# Codex Obsidian 사용 가이드

> Obsidian 안에서 OpenAI Codex CLI와 대화하고 노트를 자동 생성하는 플러그인

---

## 사전 준비

### 1. Node.js 설치 확인
터미널(PowerShell)에서:
```
node --version
```
v20 이상이어야 합니다. 없으면 https://nodejs.org 에서 설치.

### 2. Codex CLI 설치
```
npm install -g @openai/codex@latest
```

### 3. 버전 확인
```
codex --version
```

---

## 플러그인 활성화

설정 → 커뮤니티 플러그인 → **Codex Obsidian** 토글 ON

---

## 사용 방법

### 채팅 시작
왼쪽 사이드바 **💻 아이콘** 클릭

### 툴바 버튼
| 버튼 | 기능 |
|------|------|
| 📄 현재 노트 분석 | 열린 노트를 Codex가 분석 |
| 🔍 관련 노트 검색 | 볼트에서 관련 노트 검색 |
| 💻 코드 생성 | 노트 기반 코드·스크립트 생성 |
| 📋 기획서 변환 | 대화를 기획서로 정리 |
| 📝 회의록 작성 | 대화를 회의록으로 정리 |
| 💾 노트 저장 | 대화를 노트로 저장 |
| ⏹ 중지 | 생성 중단 |
| 🔄 초기화 | 새 대화 시작 |

### 승인 모드
설정에서 선택 가능:
- **제안 모드** (기본): 명령 실행 전 확인 — 초보자 권장
- 자동 모드: 안전한 명령 자동 실행
- 전체 자동: 모든 명령 자동 실행

---

## 노트 자동 저장
"저장해줘" 입력 시 → `AI/Codex/` 폴더에 자동 저장
