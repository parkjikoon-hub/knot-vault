# 막힐 때 해결 가이드

> 뭔가 안 될 때, 이 문서를 먼저 확인하세요.
> 그래도 모르면 — AI에게 바로 물어보세요!
> Claude · Gemini · Codex가 옵시디언 문제도 도와줍니다.

---

## 자주 겪는 문제 5가지

---

### ❶ 플러그인이 보이지 않아요

**증상:** 설정에 들어갔는데 Gemini Obsidian 등이 목록에 없음

**해결 방법:**
1. 설정(⚙️) → 커뮤니티 플러그인 클릭
2. **"제한 모드 해제"** 버튼이 있으면 클릭
3. "켜기" 확인
4. 이제 설치된 플러그인 목록이 보입니다

**그래도 안 되면 AI에게 물어보세요:**
```
옵시디언에서 커뮤니티 플러그인을 활성화하려고 하는데
제한 모드 해제 버튼을 눌렀는데도 플러그인이 안 보여.
어떻게 해야 해?
```

---

### ❷ API 키 오류가 나요

**증상:** "API 키가 유효하지 않습니다" 또는 빨간 오류 메시지

**해결 방법:**
1. 설정 → Gemini Obsidian (또는 Claude Obsidian)
2. API 키 칸을 **한 번 지우고** 다시 붙여넣기
3. 키 앞뒤에 공백이 없는지 확인
4. 저장 후 채팅창 닫았다가 다시 열기

**Gemini API 키 다시 발급:**
1. https://aistudio.google.com 접속
2. Get API key → Create API key
3. 새 키 복사해서 붙여넣기

**Claude API 키 다시 발급:**
1. https://console.anthropic.com 접속
2. API Keys → Create Key
3. 새 키 복사해서 붙여넣기

**AI에게 물어보세요:**
```
Gemini Obsidian 플러그인에서 API 키 오류가 나.
오류 메시지는 이거야: [오류 내용 붙여넣기]
어떻게 해결해?
```

---

### ❸ 노트가 저장이 안 돼요

**증상:** "저장해줘"라고 했는데 파일이 생기지 않음

**해결 방법:**
1. 채팅창에서 정확히 **"노트로 저장해줘"** 또는 **"저장해줘"** 입력
2. 저장 폴더 확인: 설정 → Gemini Obsidian → 저장 폴더 (`AI/Gemini` 인지 확인)
3. 왼쪽 폴더 목록에서 `AI/Gemini` 폴더 클릭해서 확인

**또는 직접 저장 버튼 사용:**
채팅창에서 AI 답변 아래 **💾 노트 저장** 버튼 클릭

**AI에게 물어보세요:**
```
Gemini Obsidian에서 "저장해줘"라고 했는데 
노트가 저장이 안 돼. AI/Gemini 폴더에도 없어.
어떻게 해결해?
```

---

### ❹ 채팅창이 열리지 않아요

**증상:** 사이드바 아이콘을 클릭해도 채팅창이 안 열림

**해결 방법:**
1. 플러그인이 켜져 있는지 확인: 설정 → 커뮤니티 플러그인 → 토글 ON
2. **Ctrl + P** → "Gemini Obsidian 패널 열기" 검색해서 실행
3. 옵시디언 완전히 종료 후 다시 실행

**AI에게 물어보세요:**
```
옵시디언에서 Gemini Obsidian 아이콘을 클릭했는데
채팅창이 안 열려. 플러그인은 켜져 있어.
어떻게 해결해?
```

---

### ❺ 옵시디언이 느려요

**증상:** 노트를 열거나 저장할 때 버벅거림

**해결 방법:**
1. 사용하지 않는 플러그인 끄기: 설정 → 커뮤니티 플러그인 → 안 쓰는 것 OFF
2. 옵시디언 완전히 종료 후 재시작
3. 노트가 너무 길면 여러 개로 나누기

**AI에게 물어보세요:**
```
옵시디언이 느린데 빠르게 하는 방법 알려줘.
플러그인은 6개 켜져 있어.
```

## 위에 없는 문제가 생겼을 때

### 방법 1 — AI에게 바로 물어보기 (가장 쉬움)

Gemini, Claude, Codex 채팅창에 이렇게 입력하세요:

```
옵시디언 사용 중에 문제가 생겼어. 도와줄 수 있어?

문제 상황: [어떤 상황인지 설명]
어떻게 했을 때 발생했는지: [무엇을 했는지]
오류 메시지: [있으면 붙여넣기]
```

AI가 단계별로 해결 방법을 알려줍니다.

---

### 방법 2 — AI에게 물어보는 추가 예시

**설치 관련 문제:**
```
옵시디언 설치는 됐는데 KNOT-vault를 열려고 하니까
[문제 상황]이 생겨. 어떻게 해?
```

**플러그인 관련 문제:**
```
[플러그인 이름] 플러그인이 제대로 작동하지 않아.
[어떤 증상인지] 이런 상황인데 해결 방법을 알려줘.
```

**노트 작성 관련:**
```
옵시디언에서 [하고 싶은 것]을 하려고 해.
어떻게 하면 돼? 단계별로 알려줘.
```

**기능 사용법을 모를 때:**
```
옵시디언에서 [기능 이름]이 뭔지 모르겠어.
쉽게 설명해주고, 언제 쓰면 유용한지도 알려줘.
```

**처음부터 다시 물어볼 때:**
```
나는 옵시디언 완전 초보야.
[현재 상황 설명]인데, 어디서부터 시작하면 좋을까?
```
