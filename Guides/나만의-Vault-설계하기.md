# 나만의 Vault 설계하기

> KNOT-vault는 시작점입니다.
> 익숙해지면 나에게 맞게 폴더를 추가하고, 구조를 바꿔보세요.
> 이 가이드는 그 방법을 알려드립니다.

---

## 폴더 구조란?

옵시디언에서 폴더는 컴퓨터의 폴더와 똑같습니다.
노트를 주제별로 묶어서 정리하는 역할을 합니다.

**KNOT-vault 기본 구조:**
```
KNOT-vault/
├── Inbox/       새로 들어온 정보 임시 보관
├── Notes/       내가 직접 쓴 노트
├── AI/          AI와의 대화 노트
├── References/  참고자료
├── Projects/    프로젝트
├── Outputs/     완성된 결과물
├── Guides/      사용 안내 (이 폴더)
└── Settings/    템플릿·설정
```

이 구조를 나에게 맞게 바꿀 수 있습니다.

---

## 폴더 추가하기

### 방법 1 — 마우스로 추가 (쉬움)

1. 왼쪽 폴더 목록에서 **빈 공간 우클릭**
2. **"새 폴더"** 클릭
3. 폴더 이름 입력 후 Enter

### 방법 2 — 기존 폴더 안에 하위 폴더 만들기

1. 상위 폴더에서 **우클릭**
2. **"새 폴더"** 클릭
3. 이름 입력

**예시 — Projects 폴더 안에 하위 폴더 만들기:**
```
Projects/
├── 2026-유튜브채널/
├── 2026-블로그운영/
└── 2026-책쓰기/
```

---

## 폴더 이름 바꾸기

1. 바꿀 폴더에서 **우클릭**
2. **"이름 바꾸기"** 클릭
3. 새 이름 입력 후 Enter

> ⚠️ 폴더 이름을 바꾸면 그 폴더를 링크로 연결한 노트들이 자동으로 업데이트됩니다.

---

## 폴더 삭제하기

1. 삭제할 폴더에서 **우클릭**
2. **"삭제"** 클릭
3. 확인

> ⚠️ 폴더를 삭제하면 안에 있는 노트도 함께 삭제됩니다. 주의하세요!

---

## 노트 만들기

### 새 노트 만들기

**방법 1:** 키보드 **Ctrl + N**
**방법 2:** 왼쪽 상단 **연필 아이콘** 클릭
**방법 3:** 특정 폴더 안에 만들고 싶으면 → 폴더 우클릭 → "새 노트"

### 노트 이동하기

1. 이동할 노트에서 **우클릭**
2. **"이동"** 클릭
3. 이동할 폴더 선택

또는 노트를 **드래그 앤 드롭**으로 폴더에 끌어다 놓기

### 노트 이름 바꾸기

노트 제목 부분을 클릭해서 직접 수정하거나
왼쪽 목록에서 노트 우클릭 → "이름 바꾸기"

## 나에게 맞는 폴더 구조 설계하기

## AI에게 나만의 구조 설계 도움받기

어떻게 구성할지 모르겠으면 AI에게 물어보세요.

```
나는 [직업/상황]이야.
옵시디언을 [목적]으로 사용하려고 해.
나에게 맞는 폴더 구조를 추천해줘.
폴더 목록과 각 폴더에 어떤 노트를 넣으면 좋은지 알려줘.
```

**예시:**
```
나는 직장인이야. 매일 회의가 많고,
배운 것들을 기록하고 싶어.
나에게 맞는 옵시디언 폴더 구조를 추천해줘.
```

## 폴더 구조 바꿀 때 팁

**처음부터 완벽하게 만들려 하지 마세요.**
쓰다 보면 자연스럽게 "이런 폴더가 필요하겠다"는 느낌이 옵니다.
그때 추가하면 됩니다.

**추천하는 순서:**
1. 일단 기본 구조(KNOT-vault)로 2주 사용
2. 불편한 점이 생기면 그때 폴더 추가·수정
3. 한 달 후 전체 구조 점검

> 완벽한 구조보다 **지금 쓰고 있는 구조**가 최고입니다. 😊

## 자주 묻는 질문

**Q. 폴더가 너무 많아지면 어떻게 해요?**
A. Ctrl+O (빠른 열기)로 노트 이름을 검색하면 폴더 위치 상관없이 바로 찾을 수 있습니다.

**Q. 폴더 안에 폴더를 몇 단계까지 만들 수 있나요?**
A. 제한은 없지만, 3단계 이상은 찾기 불편해질 수 있습니다.

**Q. KNOT-vault의 기본 폴더를 삭제해도 되나요?**
A. 네, 필요 없으면 삭제해도 됩니다. `Guides/` 폴더는 참고용이니 익숙해지면 지워도 좋습니다.
