# 자주 쓰는 단축키 10개

> 이것만 알아도 옵시디언을 훨씬 빠르게 사용할 수 있습니다.
> 외우지 않아도 됩니다. 필요할 때마다 여기서 찾아보세요.

---

## 핵심 단축키 10개

| 단축키 | 기능 | 언제 쓰나 |
|--------|------|----------|
| **Ctrl + N** | 새 노트 만들기 | 새 노트를 시작할 때 |
| **Ctrl + P** | 명령어 팔레트 열기 | 기능을 찾을 때 (가장 많이 씀) |
| **Ctrl + E** | 편집 ↔ 미리보기 전환 | 노트를 보기 좋게 볼 때 |
| **Ctrl + F** | 현재 노트에서 검색 | 노트 안에서 단어 찾을 때 |
| **Ctrl + O** | 노트 빠른 열기 | 노트 이름으로 빠르게 찾을 때 |
| **Ctrl + S** | 저장 | 노트 저장 (자동저장도 되지만) |
| **Ctrl + Z** | 되돌리기 | 실수했을 때 |
| **Ctrl + /** | 현재 줄 주석 처리 | 임시로 내용 숨길 때 |
| **Ctrl + B** | **굵게** | 중요한 단어 강조 |
| **Ctrl + I** | *기울이기* | 강조 표현 |

---

## 가장 많이 쓰는 것 TOP 3

**1위: Ctrl + P (명령어 팔레트)**
모르는 기능이 있으면 무조건 Ctrl+P 누르고 검색하세요.
옵시디언의 모든 기능이 여기에 있습니다.

**2위: Ctrl + N (새 노트)**
아이디어가 떠오를 때 바로 새 노트를 열어서 기록하세요.

**3위: Ctrl + O (노트 빠른 열기)**
노트가 많아졌을 때 이름으로 빠르게 찾을 수 있습니다.
