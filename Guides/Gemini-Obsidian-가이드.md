# Gemini Obsidian 사용 가이드

> Obsidian 안에서 Google Gemini AI와 대화하고, 노트를 자동 생성하는 플러그인

---

## 설치 확인

이미 KNOT-vault에 설치되어 있습니다.
설정 → 커뮤니티 플러그인 → **Gemini Obsidian** 토글 ON

---

## API 키 발급 (무료)

1. https://aistudio.google.com 접속
2. 구글 계정으로 로그인
3. 왼쪽 메뉴 **"Get API key"** 클릭
4. **"Create API key"** 클릭
5. 생성된 키 복사 (AIza... 로 시작)

---

## API 키 입력

옵시디언 설정(⚙️) → **Gemini Obsidian** → API 키 칸에 붙여넣기

---

## 사용 방법

### 채팅 시작
왼쪽 사이드바 **✨ 아이콘** 클릭 → 채팅창 열림

### 메시지 전송
- 메시지 입력 후 **Shift + Enter**

### 툴바 버튼
| 버튼 | 기능 |
|------|------|
| 📄 현재 노트 요약 | 열린 노트를 Gemini가 요약 |
| 🔍 관련 노트 검색 | 볼트에서 관련 노트 검색 |
| 📋 기획서 변환 | 대화를 기획서로 정리 |
| 📝 회의록 작성 | 대화를 회의록으로 정리 |
| ✅ 액션 아이템 | 할 일 목록 추출 |
| 💾 노트 저장 | 대화를 노트 파일로 저장 |
| 🔄 초기화 | 새 대화 시작 |

### 노트 자동 저장
대화 중 **"저장해줘"**, **"노트로 만들어줘"** 입력 시
→ `AI/Gemini/` 폴더에 자동 저장됩니다.

---

## 팁

- 노트를 열어두면 Gemini가 그 내용을 자동으로 참고합니다
- 모델 변경: 설정 → Gemini Obsidian → 모델 선택
  - Gemini 1.5 Flash: 빠르고 무료
  - Gemini 2.0 Flash: 최신 버전
