# Gemini Obsidian 사용 가이드

> Google Gemini AI를 옵시디언 안에서 바로 사용하는 플러그인
> **무료**로 사용할 수 있어서 처음 시작하는 분께 추천합니다.

---

## 시작 전 확인

- [ ] 옵시디언이 설치되어 있다
- [ ] KNOT-vault를 옵시디언에서 열었다
- [ ] Gemini API 키를 발급받았다 (아래 방법 참고)

---

## STEP 1. Gemini API 키 발급받기 (무료)

API 키는 Gemini AI를 사용하기 위한 **비밀번호** 같은 것입니다.
구글 계정만 있으면 무료로 발급받을 수 있습니다.

1. 인터넷 브라우저에서 **https://aistudio.google.com** 접속
2. 오른쪽 위 **"Sign in"** 클릭 → 구글 계정으로 로그인
3. 왼쪽 메뉴에서 **"Get API key"** 클릭
4. 파란 버튼 **"Create API key"** 클릭
5. 팝업창에서 **"Create API key in new project"** 클릭
6. 화면에 나타나는 긴 문자열을 **복사** (AIza... 로 시작하는 문자)
   - 복사 버튼(📋 아이콘)을 클릭하면 됩니다

> ⚠️ API 키는 다른 사람에게 알려주지 마세요. 비밀번호와 같습니다.

---

## STEP 2. 플러그인 활성화

1. 옵시디언 왼쪽 아래 **톱니바퀴(⚙️)** 클릭
2. 왼쪽 메뉴 **"커뮤니티 플러그인"** 클릭
3. **"제한 모드 해제"** 버튼이 보이면 클릭 → "켜기" 확인
4. 설치된 플러그인 목록에서 **"Gemini Obsidian"** 찾기
5. 오른쪽 토글 스위치 클릭해서 **파란색(ON)** 으로 변경

---

## STEP 3. API 키 입력

1. 설정(⚙️) → 왼쪽 메뉴 맨 아래 스크롤
2. **"Gemini Obsidian"** 클릭
3. **"API 키"** 칸 클릭
4. 아까 복사한 키 붙여넣기 (Ctrl+V)
5. 설정 창 닫기 (X 버튼 또는 ESC)

---

## STEP 4. 사용 시작!

### 채팅창 열기
옵시디언 왼쪽 사이드바에서 **✨ 반짝이 아이콘** 클릭
→ 오른쪽에 Gemini 채팅창이 열립니다

### 메시지 보내기
1. 아래 입력창에 내용 입력
2. **Shift + Enter** 키를 누르면 전송

---

## 주요 기능 사용법

### 툴바 버튼 (채팅창 위쪽에 있는 버튼들)

| 버튼 | 클릭하면 |
|------|---------|
| 📄 현재 노트 요약 | 지금 열려있는 노트를 Gemini가 요약해줍니다 |
| 🔍 관련 노트 검색 | 현재 주제와 관련된 내 노트를 찾아줍니다 |
| 📋 기획서 변환 | 지금까지 대화를 기획서 형식으로 정리합니다 |
| 📝 회의록 작성 | 지금까지 대화를 회의록 형식으로 정리합니다 |
| ✅ 액션 아이템 | 대화에서 해야 할 일만 뽑아서 목록으로 만듭니다 |
| 💾 노트 저장 | 대화 내용을 노트 파일로 저장합니다 |
| 🔄 초기화 | 대화를 지우고 새로 시작합니다 |

### 노트 자동 저장
대화 중에 이렇게 입력하면 자동으로 노트가 만들어집니다:
- **"저장해줘"**
- **"노트로 만들어줘"**
- **"기획서로 정리해줘"**

저장된 노트는 `AI/Gemini/` 폴더에서 찾을 수 있습니다.

### 현재 노트 내용 참고시키기
노트를 열어두고 Gemini에게 질문하면,
Gemini가 그 노트 내용을 자동으로 참고합니다.

예시:
1. 노트 하나를 열어두기
2. Gemini 채팅창에서 **"이 내용 요약해줘"** 입력
3. Gemini가 열린 노트 내용을 보고 요약해줍니다

## 모델 변경 (더 좋은 AI 사용하기)

기본값은 **Gemini 1.5 Flash** (빠르고 무료)입니다.
더 똑똑한 AI를 원하면 설정에서 변경할 수 있습니다.

설정(⚙️) → Gemini Obsidian → 모델 선택:

| 모델 | 특징 |
|------|------|
| Gemini 1.5 Flash | 빠름, 무료 한도 넉넉 (추천) |
| Gemini 2.0 Flash | 더 최신, 무료 |
| Gemini 1.5 Pro | 더 정확, 유료 |

## 자주 묻는 질문

**Q. "API 키가 유효하지 않습니다" 오류가 나요**
A. API 키를 다시 복사해서 붙여넣어 보세요. 앞뒤 공백이 들어가면 안 됩니다.

**Q. 응답이 너무 느려요**
A. 모델을 "Gemini 1.5 Flash"로 바꿔보세요. 가장 빠릅니다.

**Q. 한국어로 대화해도 되나요?**
A. 네, 한국어로 입력하면 한국어로 답변합니다.

**Q. 하루에 얼마나 사용할 수 있나요?**
A. 무료 한도는 하루 약 1,500회 요청입니다. 일반 사용에는 충분합니다.
